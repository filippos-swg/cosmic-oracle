# ASTRA — DESIGN.md
Status: Creative Runtime pilot. Subordinate to `aios/CANON.md`.

## Design proposition
ASTRA is an atmospheric instrument, not an application. It should feel like an old machine that has catalogued the cosmos for a long time and has only recently decided to speak.

## Principles
### 1. Instrument, not interface
Avoid app chrome, panels, cards, navigation conventions, buttons and decorative controls unless the physical interaction genuinely requires them.

### 2. The phenomenon is primary
The entity/sky/instrument field owns the screen. Information appears within that world rather than sitting on top as conventional UI.

### 3. Restraint creates mystery
Black and white first. Spectral, minimal, precise. Mystery comes from withholding and specificity, not visual effects.

### 4. Two registers, one object
Machine layer: cold, symbolic, compressed, archival, technical.
Human layer: readable, calm, dry, intelligent.
Their tension is the identity. Do not collapse them into either horoscope warmth or abstract generative art.

### 5. CRT reality outranks browser taste
This is a 4:3 physical installation viewed through a vintage television. Legibility, safe areas, contrast and optical behaviour on the actual display outrank desktop-browser elegance.

## Typography
The existing JetBrains Mono-led ceremony is an authored decision. Preserve its instrumental character unless testing proves a change materially improves the physical experience.
Hierarchy should come primarily from scale, spacing, tracking, position and timing rather than extra font styles or colour.

## Composition
- Preserve negative space.
- Central reading content must remain dominant.
- Metadata is evidence/context, not decoration.
- Prefer asymmetry only when it feels instrumental rather than editorial-fashionable.
- Every visible element should plausibly belong to the same machine.

## Colour and effects
Default: black, off-white, controlled grey hierarchy.
Avoid neon, rainbow spectral gradients, purple/blue AI palettes, glass, glossy bloom, decorative glow and occult colour coding.
Any exception requires a functional or conceptual reason.

## Anti-patterns
No:
- SaaS cards
- dashboard grids
- generic AI orb/blob
- zodiac-wheel cliché
- witchcore
- cyberpunk HUD
- gratuitous particles
- faux-terminal decoration with no system meaning
- visual complexity added to imply intelligence

## Evaluation
A successful frame should be identifiable as ASTRA even with the word ASTRA removed.
