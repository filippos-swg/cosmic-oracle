# ASTRA — REFERENCES.md

References are evidence, not moodboard decoration. Every reference must answer a named design question.

## Existing conceptual territory
See `aios/CANON.md`: Borges, Ursula K. Le Guin, restrained Douglas Adams operations, SCP archival/systemic language, Ryoji Ikeda, oscilloscopes, scientific instrumentation, experimental editorial typography, observatory metadata.

## External research protocol
For every new reference record:
- Reference
- Question it helps answer
- Specific useful property
- What NOT to copy
- Decision or experiment produced

## Refero
Use Refero Styles when a concrete UI/design-system question exists, especially typography, spacing, hierarchy or component behaviour. Do not browse until something attractive appears and then retrofit ASTRA around it.

## Component libraries
OriginKit / Componentry / Skiper may be consulted for techniques or primitives in projects whose stack supports them. ASTRA installation is currently dependency-free; no component library is approved by default.

## Reference rejection is useful
Record strong references we deliberately reject when the rejection clarifies ASTRA's identity.
