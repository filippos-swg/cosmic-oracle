# ASTRA / Cosmic Oracle — Canon

The locked identity of this project. Do not drift from this.

---

## The One Sentence

> A strange machine that interprets incomprehensible symbolic weather into human language.

---

## The One Distinction

> A cold symbolic machine with a warm, dry, intelligent translation layer.

That is the product. That balance is everything. Tip too far in either direction and it breaks:
- Too human-facing → becomes a horoscope app
- Too abstract → becomes inaccessible generative art

---

## What This Is

A symbolic atmospheric interpretation machine.

The system:
1. reads actual astronomical sky data
2. compresses the sky into symbolic signatures
3. interprets those signatures through a token library
4. translates meaning into grounded horoscope prose
5. renders the result as an atmospheric instrument, not an app

---

## What This Is Not

- a generic horoscope app
- a chatbot with zodiac styling
- mystical AI slop
- neon cyberpunk astrology
- spiritual influencer content
- "witchcore" aesthetics
- fake wisdom quotes
- gamified horoscope UX
- comedy parody astrology
- generic generative art

---

## The Two Layers

### Machine Layer
Cold. Symbolic. Compressed. Instrumental.

Tone: archival, bureaucratic, systemic, technical-poetic.

Outputs signatures like:
```
SUN_TRI_JUP
VEN_CON_SAT
MOO_OPP_SAT
STACK_PISCES_4
```

These are not decorative labels. They are compressed archetypal states, generative seeds, symbolic runtime tokens, visual drivers, interpretation handles.

### Human Translation Layer
Warm enough to be readable. Never sentimental.

Voice: self-aware cosmic librarian.
Tone: calm, intelligent, observational, slightly wry, grounded, companionable but not chatty.

---

## Voice Identity

**The persona:** A self-aware cosmic librarian.

**Not:**
- mystical guru
- comic parody
- Monty Python absurdism
- spiritual influencer
- friendly chatbot
- motivational coach

**Douglas Adams influence:** Restraint reference only, not imitation. Allowed: dry cosmic understatement, contrast between planetary scale and mundane behavior. Not allowed: absurdist comedy, mocking astrology.

**Wit rule:** Maximum one gently wry observation per reading. Maximum one cosmic-mundane contrast. The wit must never undermine the astrological craft.

**Language rules:** No em dashes. No exclamation marks. No emojis. No ellipses. No prophecy language ("will", "must", "destined"). Use probabilistic language: "may", "might", "appears", "suggests".

---

## Visual Canon

Black and white first. Spectral. Minimal. Precise. Atmospheric. Instrument-like.

Elements: ghost membrane, orbital rings, aspect lines, symbolic signatures, metadata overlays, oscilloscopic movement, typographic annotations.

Avoid: neon zodiac wheels, glowing gradients, fantasy symbols, cartoon stars, occult cliché, generic AI blobs, glossy UI.

---

## The North Star

Build a symbolic atmospheric system that reads the sky, compresses it into machine states, and translates it into human-scale meaning with restrained wit and visual intelligence.

The object should feel like: **an old machine that has been cataloguing the cosmos for a long time and has only recently decided to speak to humans.**
